# DZ LAB в собственном Cloudflare

Режим первого запуска: публичный каталог и конфигуратор без входа. Черновик и до 100 сохранённых сборок хранятся в localStorage этого браузера. Очистка данных браузера удаляет их. Для передачи состава используется TXT; ссылки на локальные сборки открываются только в том же браузере. Серверное сохранение и MCP на внешнем хостинге закрыты.

## Сборка и публикация

Node.js 24, pnpm 11.25.0 из package.json. Установка: pnpm install --frozen-lockfile. Проверка: pnpm exec tsc --noEmit и node --test tests/*.test.mts. Сборка: pnpm run build:cloudflare. Публикация: pnpm run deploy:cloudflare. Локально: pnpm run dev:cloudflare.

Workers Builds: репозиторий prepodobniy77/dz-lab, ветка main, build command pnpm run build:cloudflare, deploy command pnpm run deploy:cloudflare. Переменная сборки NODE_VERSION=24.22.2. Секреты не нужны для публичного каталога.

wrangler.static.jsonc публикует статическую React SPA на Cloudflare без серверного рендеринга и без D1: для выбранного первого запуска база не нужна. Страница и /api/catalog используют data/catalog.json, сборки хранятся только в браузере. Публичная выдача автообновлений доступна через GET /api/prices/current. Рабочие данные исходной D1 Sites этим способом не переносятся.

## Обновление цен

GitHub Actions проверяет известные предложения в 06:00 и 18:00 МСК. Workflow сохраняет публичные результаты в ветке price-snapshots. Cloudflare проксирует этот снимок, а конфигуратор применяет только проверенные цены с более свежей датой. Подробности в PRICE-UPDATES.md.

## Совместная работа с Claude Code и Codex

Код хранится в GitHub. Перед задачей обновляйте main, используйте отдельные ветки и pull requests. Сохранены исходные команды Sites; для внешнего Cloudflare используйте команды с суффиксом :cloudflare. Внешняя сборка использует Vite + React и выдачу статических файлов, без Sites, с прокси публичного снимка цен. Она не принимает заголовки идентичности и не содержит механизмов платного обновления. Сохранён и прежний серверный вариант (build:cloudflare-ssr), но он не используется: внешний SSR каталога превысил лимит CPU Workers (ошибка 1102).

Проверки при подготовке: TypeScript и 77 тестов прошли; внешняя production-сборка проходит. Статическая сборка заменяет SSR после обнаружения ошибки 1102 на внешнем адресе. Успешную публикацию проверять отдельно по фактическому URL.
