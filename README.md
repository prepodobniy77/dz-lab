# DZ LAB — конфигуратор ПК

React 19, TypeScript, Cloudflare Workers и D1. [Основной сайт](https://dz-lab.dimkaaistov.workers.dev/). Внешняя версия — React SPA, сервер `worker/external.ts`, конфигурация `wrangler.jsonc`.

Десять категорий, двадцать редактируемых конфигураций, проверка распознанных параметров совместимости. Сборки сохраняются в браузере. Аккаунты и облачное сохранение на внешнем сайте не подключены; `TRUST_OAI_HEADERS=0`. Цены компьютеров рассчитываются из предложений комплектующих. SO-DIMM исключена.

## Источники и свежесть

[Исследование источников](PRICE-SOURCES.md) отделяет подтверждённые каналы от исторических снимков. `data/catalog.json` не доказывает текущую цену. BOX/OEM и разные артикулы не объединяются по названиям.

Адаптеры `lib/providers` возвращают источник (`api / feed / snapshot`), дату, Москву и RUB:

- XCOM: существующий ограниченный обход с проверкой robots.txt и остановкой при блокировке.
- DNS: только предоставленный разрешённый CSV/YML-фид, без HTML-парсинга. Без URL плановый импорт пропускается.
- Delect: полный экспорт по ключу с проверкой охвата; sample отклоняется. Это закупочный прайс поставщика, не розничный API DNS. Может требовать фиксированный IP; платный доступ не оформлялся.

Привязка по MPN/SKU/подтверждённой ссылке. Охват ниже 80% не публикуется без явного исключения владельца для фида. Скачки больше 50% задерживаются; два последовательных наблюдения в пределах 2% подтверждают изменение. Пропуски не удаляют старые предложения и не обновляют их даты.

До 12 ч — «Актуально», до 36 ч — «Проверено вчера», до 72 ч — «Могла устареть». Старше 72 ч не участвует в лучшей цене. Без свежих предложений — «Нет данных».

## Расписание

После публикации этой конфигурации Cloudflare Cron: **06:00 и 18:00 МСК**, резерв GitHub: **06:20 и 18:20**, DNS: **06:40 и 18:40**. Переменные частоты ограничивают запросы источников. Sites не является основным исполнителем.

Панель `/admin/prices` принимает ключ задания без сохранения в браузерном хранилище. При задержке подключённого источника больше 26 ч — красное предупреждение. Telegram опционален. В отчёте виден возраст самой старой цены по магазинам.

Зелёная сборка не подтверждает обновление цен: нужны новые `checkedAt` и запись успешного цикла. **Для DNS/Delect без предоставленного доступа: код готов, запуск не проверен.**

## Локальная проверка

Node 24+, pnpm 11.25.0. Статическая сборка не обращается к D1 или секретам.

```sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
node --test tests/*.test.mts
pnpm run build:cloudflare
pnpm exec wrangler d1 migrations apply dz-lab-db --local --config wrangler.jsonc
pnpm exec wrangler dev --config wrangler.jsonc --local
```

Для интерфейса: `pnpm run dev:cloudflare` (снимок, без защищённых серверных маршрутов).
Тесты используют локальную D1 и искусственные ответы: свежесть, идентичность, охват, скачки, блокировки, повтор/прерывание импорта, атомарность. Они не подтверждают доступность магазинов или доставку Telegram.

## Маршруты внешнего Worker

| Маршрут | Назначение |
|---|---|
| `GET /api/catalog` | Каталог с подтверждёнными предложениями |
| `GET /api/prices/sweep` | Публичный итог и последний успешный цикл |
| `GET /api/prices/sources` | Расписание, происхождение и возраст цен |
| `GET /api/prices/import` | Публичное время, статус и количество обновлений |
| `GET /api/prices/status` | История владельцу, Bearer PRICE_JOB_TOKEN |
| `POST /api/prices/sweep` | Защищённый запуск/продолжение порции |
| `POST /api/prices/import` | Защищённый CSV/YML или порционный импорт |
| `/api/prices/import/reviews` | Защищённый список и решения по скачкам |
| `/api/builds` | Отключён, 404; сохранение в браузере |
| `POST /api/prices/refresh` | Посетителю недоступен, 401 |

Два полных импорта DNS плюс XCOM могут приблизиться к 100 000 записей D1 Free в сутки или превысить их. Перед подключением полного фида нужен реальный замер; платный план автоматически не подключается.

Неизвестные характеристики не дорисовываются. Проверка совместимости не заменяет CPU Support List, BIOS, QVL и проверку разъёмов. Цена не включает доставку, сборку, ОС и может измениться. FPS без подтверждённых данных не показывается. Остальные этапы требуют отдельного подтверждения владельца.
