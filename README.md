# DZ LAB — PC Build Studio

React 19 / TypeScript / Vinext / Cloudflare Workers / D1.

Рабочий конфигуратор из 10 категорий с импортом реального каталога, ценами магазинов, базовой проверкой совместимости, сравнением до 3 товаров и сохранением сборок на сервере.

## Данные и источники

`data/catalog.json` содержит 1 538 позиций десяти категорий XCOM-SHOP (Москва): до шести страниц и крайние ценовые подборки. Это ограниченный ассортимент одного продавца, не весь рынок. У исходных 352 моделей есть подробные характеристики из карточек; для всех 122 HDD и 141 СЖО также загружены подробные характеристики и артикулы. Остальные новые позиции содержат краткие сведения листинга, неизвестные характеристики не дорисовываются. Дополнительно подключены KNS (4 предложения CPU), Регард (66 совпадений), CompDay (40 совпадений CPU) и e2e4 (2 предложения). DNS и Ситилинк содержат по 4 подтверждённые ссылки на карточки, но серверные запросы сейчас ограничены HTTP 401/429: цены для них не выдумываются и в итог не включаются. Онлайн Трейд возвращает служебную страницу, НИКС — ограничение доступа, Ф-Центр — HTTP 503; они показаны со статусом недоступности. Реальный охват и даты указаны в интерфейсе. BOX/OEM и разные артикулы не объединяются на основании похожих названий.

Все цены в каталоге получены из `data-price` карточки листинга или из микроданных `Offer`/JSON-LD страницы товара. Для CompDay используется `data-price` основной карточки; условия скидки отображаются отдельно. У каждого предложения есть URL, магазин, наличие и время проверки. Импорт не гарантирует актуальности цены в момент покупки. Доставка, сборка, ОС, б/у и клубные скидки не включены.

## Запуск

Node.js 24+ и pnpm.

```bash
pnpm install
pnpm dev
```

Для локального D1 сначала выполните сборку и примените миграцию:

```bash
pnpm build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_mushy_albert_cleary.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_classy_sugar_man.sql
```

`.openai/hosting.json` должен содержать `"d1":"DB"`.

## Исследование и воспроизводимый импорт

```bash
node --experimental-strip-types scripts/import-catalog.mts
node --experimental-strip-types scripts/enrich-catalog.mts
node --experimental-strip-types scripts/enrich-details.mts
node --experimental-strip-types scripts/enrich-details.mts --remaining
node --experimental-strip-types scripts/sync-retailers.mts
```

Исходный импорт использует два ограниченных параллельных запроса, расширение по магазинам выполняется последовательно, без обхода защит и автоматических повторов. Сначала импортируются списки, затем предложения KNS, затем характеристики карточек. `data/import-report.json` сохраняет количество найденных карточек и ошибки каждого запроса. Убедитесь в успешном завершении до публикации нового снимка.

## API цен (новое)

Новые проверки цен выполняет **Delect API Lite**, а не HTML-парсер под видом API. Интеграция не активирована: ключа владельца нет. DNS API не подключён. Существующие розничные наблюдения и расширение каталога — снимки открытых HTML-страниц; в предложениях стоит `transport: html-snapshot`. Их нельзя описывать как цены из API.

Документация: https://delect.ru/delect-api/ . Полный API требует учётную запись компании и соответствующий тариф; тестовые 100 строк не заменяют полный прайс. Закупочные цены поставщиков не равны розничным и маркируются отдельно.

Секреты: `DELECT_API_KEY`, `DELECT_DISTRIBUTOR`. Не передавать ключ в браузер, коммит или URL. Поддерживаются серверный импорт и защищённый POST. Сервис привязывает ключ к IP при первом запросе. **Cloudflare Workers не гарантирует постоянный исходящий IP: для надёжной работы запускайте импорт на собственном сервере с фиксированным IP и публикуйте полученный снимок.** Не используйте один привязанный ключ с разных машин. Hosted secrets настраиваются владельцем через Sites; адаптер Worker можно использовать только при подтверждённом доступе с его исходящего адреса.

```bash
# Переменные задаются через защищённое окружение сервера
node --experimental-strip-types scripts/import-api-prices.mts
node --experimental-strip-types scripts/expand-catalog.mts
```

API импорт проверяет EOF/count, отказывается от sample, повреждённого/слишком большого ответа, нулевых цен, неизвестной даты, другого поставщика. Сопоставление — точный MPN. Снимок записывается атомарно только после проверки. API ошибки никогда не запускают HTML fallback.

## Сервер

- `GET /api/catalog` — импорт + обновлённые предложения из D1.
- `POST /api/prices/refresh` — `{ids: ["xcom-1057035"]}`, от 1 до 10 товаров; вход через ChatGPT обязателен. Только Delect API, без HTML fallback. Без ключа возвращает 503 с причиной. Полный прайс ограничен 24 МБ, запрос — 45 сек, между запросами 15 минут. Отсутствующий MPN не получает подставную цену.
- `GET /api/builds` — до 50 последних сохранённых сборок.
- `POST /api/builds` — `{name,selection}`; в `selection` используются только существующие ID и категории.
- `GET /api/builds/:id` — сохранённая сборка.
- `/build/:id` — открыть сохранённую сборку в конфигураторе.

D1: `price_offers` — последние результаты проверок; `price_history` — успешные наблюдения; `builds` — сохранённые подборки; `source_health` — состояние ограничений магазинов. Локальный черновик хранится в браузере. Текущий сайт публичный: каталог и опубликованные ссылки на сборки доступны посетителям. Для сохранения и запуска обновления нужен вход через ChatGPT; записи сборок остаются общими, персональное разделение данных внутри приложения не реализовано.

## Проверка

```bash
node --experimental-strip-types --test tests/*.test.mts
pnpm exec tsc --noEmit
pnpm build
```

Тестируются извлечение цены из основного Offer, исключение рекомендаций, валюты и отсутствующих цен, остатки, MPN и источник данных, несовпадение сокетов и DDR, рекомендация мощности БП и обработка неизвестных параметров.

## Пределы проверки совместимости

Проверяются распознанные сокеты CPU/платы, DDR, поддержка креплений кулера, форматы платы/корпуса, доступные размеры GPU/корпуса и кулера/корпуса, рекомендация мощности GPU. Неизвестные параметры дают предупреждения. BIOS/CPU Support List, QVL, все кабели и разъёмы, линии PCIe, реальные зазоры и температурный режим требуют проверки у производителей. Сообщение «явных конфликтов нет» не означает гарантированную совместимость.

Оплата и оформление заказов не подключены. Внешние изображения остаются на CDN продавца и могут стать недоступны.

## Расширение магазинов

`lib/stores.ts` — реестр разрешённых доменов. `data/retailer-links.json` — проверенные ссылки DNS, Ситилинк и e2e4. `scripts/sync-retailers.mts` сопоставляет Регард по vendorcode/MPN и CompDay по MPN индивидуальной карточки. `data/retailer-sync-report.json` сохраняет успехи и причины отказов. Команда останавливает запросы к магазину при HTTP 401/403/429; никакого обхода защит не выполняется. Для CompDay после исправления парсера есть ограниченный режим `--compday-only`, не запускающий остальные магазины повторно.


Расширенный каталог: десять категорий, HDD и СЖО отдельно. HDD необязателен; кулер и СЖО взаимоисключающие. Каталог расширяется аддитивно (сохраняются другие магазины и характеристики); конкретный объём и ошибки — `data/expansion-report.json`. Для СЖО неизвестные посадочные размеры корпуса дают предупреждение, а не зелёную гарантию.


## Готовые сборки и новая палитра

Во вкладке «Сборки» есть 20 редактируемых конфигураций: 4 офисные, 3 бюджетные, 8 игровых, 3 рабочих и 2 премиальных. Они находятся в `data/ready-builds.json` и не засоряют пользовательскую таблицу builds. Цены считаются из текущих предложений каталога, без выдуманных фиксированных цен или FPS. Фильтры: назначение, бюджет, модель железа, сортировка. «Состав» показывает все компоненты и предупреждения; «Настроить» открывает отдельный черновик в конфигураторе. На внешнем сайте сборки сохраняются в браузере. В отдельной версии Sites облачное сохранение требует входа.

Палитра: графитовый фон, холодный синий акцент и светлый текст.

## Автоматическое обновление цен

Основной исполнитель — Cloudflare Cron Trigger ежедневно в **06:00 МСК** (`0 3 * * *` UTC). GitHub Actions служит резервом в 06:20 МСК и пропускает запуск, если с последнего успешного цикла прошло меньше шести часов. Задание Sites выключено.

Worker хранит проверенные предложения, курсор порционного обхода и историю циклов в D1. Импорт `data/catalog.json` сохраняет исходные `checkedAt`. Публичный `GET /api/prices/sweep` показывает время, статус, число обновлённых цен и время последнего успеха. История доступна владельцу через `GET /api/prices/status` с Bearer-секретом.

На внешнем сайте `TRUST_OAI_HEADERS=0`. Посетители сохраняют сборки в браузере. Ручной запуск цикла доступен владельцу через GitHub Actions или защищённый API.
