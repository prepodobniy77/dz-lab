## Ограничения доступа

В robots.txt DNS у общего агента разрешены обычные пути, есть отдельные разрешения для пагинации и запреты на произвольные параметры, поиск и служебные разделы. Это не отменяет антибот-защиту и правила магазина. Историческая проверка каталога возвращала 401; HTML-парсер DNS не добавлялся. Для Ситилинка также не используются смена агента, прокси, капчи или защищённые внутренние API. Ошибки доступа не заменяются выдуманными ценами.

## Delect — отдельный источник

[Официальная документация Delect](https://delect.ru/delect-api/) описывает NDJSON API с датами `updated_at`. Это прайс поставщика, **не официальный розничный API DNS или другого магазина**. Нужны собственный ключ, выбранный поставщик, полный экспорт и разрешённый исходящий IP. Тестовый sample отклоняется. Платный доступ не подключался; цену и договор владелец согласует отдельно. Workers не обеспечивает фиксированный исходящий IP: наличие адаптера не доказывает доступность API с Cloudflare.

## Контракт адаптера

`lib/providers/types.ts`: `PriceProvider.fetchOffers(context)` возвращает `OfferBatch | null` с `store`, `source: api | feed | snapshot`, `exportedAt`, `region`, `currency` и сопоставленными предложениями. `null` — источник не настроен либо порция отложена. Дата наблюдения не заменяется временем скачивания.

Логика магазина из реестра находится в одном файле в `lib/providers/`: `export default` объекта `PriceProvider`, включая `isConfigured(config)`. Статическая сборка автоматически создаёт `index.ts` из файлов адаптеров; этот реестр также хранится в Git для запуска CLI без сборки. Новый API-адаптер автоматически попадает в исполнитель полных прайсов и отчёт источников. Адаптер обязан проверять полноту/80% охвата, даты, идентичность и условия доступа. Для разработки реестра без сборки можно вызвать `generatePriceProviders('./lib/providers')` из `scripts/generate-price-providers.mts`.

DNS идёт через staging фида, XCOM — порционный обход, Delect — проверяемый полный экспорт. Новому магазину за пределами `lib/stores.ts` также нужны разрешённые домены в реестре; новый способ транспорта требует отдельного исполнителя. Генерация реестра не даёт разрешения на получение данных и не включает платные доступы.

Для запуска официальных источников пока требуются данные владельца из таблицы. Этот PR не доказывает автоматическое получение свежих цен всех магазинов.
